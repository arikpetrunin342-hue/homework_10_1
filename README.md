# homework__10_1

Учебный проект по работе с GitHub и списками словарей в Python.

## Функционал

- **Фильтрация данных**: функция `filter_by_stake` отбирает записи по статусу (по умолчанию - `'EXECUTED'`).
- **Сортировка данных**: функция `sort_by_date` сортирует записи по дате. По умолчанию сортировка идёт по убыванию, но можно изменить порядок.
- **Генерация тестовых данных:** модуль `generators.py` содержит функции-генераторы для создания синтетических наборов данных.
Они используются в тестах для имитации реальных банковских транзакций и номеров карт без необходимости обращения к внешним источникам или базам данных.

## Тестирование

Проект покрыт модульными тестами. Они проверяют каждую функцию отдельно.

**Что здесь тестируется:**

- Функции маскировки номеров карт`(test_mask.py)` - стандартные случаи, неправильные форматы, пустые строки.
- Обработчик дат`(test_widget.py)` - валидные и неверные форматы.
- Логика сортировки и фильтрации списков`(test_processing.py)` - работа с реальными наборами данных.
- Функция `(card_number_generator)` генерирует номера банковских карт в формате `XXXX XXXX XXXX XXXX`.
Диапазон генерации ограничен от `0000 0000 0000 0001` до `9999 9999 9999 9999`.
